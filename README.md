# Zoho Meeting — AI Description Generator Prototype

Single-file prototype for the "Generate with Zia" feature using Platform AI.

## Deploy to GitHub Pages

1. Create a new repo on GitHub
2. Push this folder:
   ```bash
   git init
   git add .
   git commit -m "Zoho Meeting AI prototype"
   git remote add origin https://github.com/YOUR_USERNAME/zoho-meeting-prototype.git
   git branch -M main
   git push -u origin main
   ```
3. Go to repo **Settings** → **Pages**
4. Source: **Deploy from a branch**
5. Branch: **main** / **root**
6. Click **Save**
7. URL will be: `https://YOUR_USERNAME.github.io/zoho-meeting-prototype/`

Share the URL with your team.
